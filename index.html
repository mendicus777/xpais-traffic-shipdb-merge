ShipDB Merger

Compare your personal ShipDB with the central ShipDB. You can download an updated personal copy, submit new or missing vessel data for manual review, and synchronize the last_seen_utc dates of vessels whose data already matches. Your full personal database is never uploaded.

1. Central database

The central ship_db.csv is stored in private Cloudflare R2 storage; this page (GitHub Pages) only hosts the merger. Access is restricted to approved VesselPack owners, each using an individual access token. Request your token by private message on X-Plane.org or through my Ko-fi Shop. Store it securely (e.g. in KeePass) and do not share it. Tokens cannot be retrieved later. This page does not save your token.

Enter your personal access token to load the central database.

2. Your database

Select your local ship_db.csv (from the plugin's ShipDB folder). It is read locally in your browser.

Changing an option recalculates the comparison. The contribution never depends on the first option.

Waiting for the central database and your CSV.

3. Comparison results

Core vessel data (ship_type, length_m, beam_m) changes only through manual contribution review. last_seen_utc is not part of a contribution: when all core values of a vessel match the central record and your date is newer, the date can be synchronized automatically. A ship_type of 0 or an empty/invalid value counts as missing. New MMSIs get their central entry only after review and publication; your local date for them is synchronized on a later comparison.

Synchronize last-seen dates

Sends only MMSI, the three core values and your date for vessels whose core data matches the central record exactly. The central file is updated immediately; nothing else is changed. Daily limit per user: 10,000 executed updates.

Compare first.

Submit contribution for review

Uploads only the contribution CSV (mmsi,ship_type,length_m,beam_m) to the private review queue. It does not change the central database until it is reviewed and published. Repeating an upload of the same content does not create a second submission.

Compare first.

Skipped contribution records

Only records with a 9-digit MMSI, an AIS type 1–99 and a LOA and beam greater than 0 can be contributed. Skipped records are listed with the reason and are not exported.
