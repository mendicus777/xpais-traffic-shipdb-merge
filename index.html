ShipDB Merger

Compare your personal ShipDB against the central repository database. Download an updated personal copy and a separate contribution file for review. Only the generated contribution CSV is uploaded if you choose to submit it; your full personal database is not uploaded.

1. Central database

The central ship_db.csv is stored in a private Cloudflare R2 bucket and is retrieved only after the CSV access password is verified.
